⚡ LangGraph 11-Step Conversational State Graph

Every employee question is executed as an immutable state trajectory across 11 specialized nodes:

01
load_employee_facts SQL Ingestion
Connects to omni_hr.db via SQLAlchemy 2.0 ORM. Injects authenticated employee facts: total leave entitlement, remaining balance, probation status, and current line manager.
02
understand_query Structured Extraction
Classifies intent (Greeting, Policy, SQL balance, Leave action, School document), detects language (Arabic/English), extracts temporal anchors (e.g. "next Monday"), and flags missing parameters.
03
Intent Decision Gate Dynamic Routing
Routes the conversation execution to specialized sub-pipelines based on intent:
⚡ Greeting Fast Path

Instant personalized welcome with employee's name + 5 capability bullets + unified Quick Actions.

❓ Clarification Pause

Prompts user for missing dates/types. Saves turn state to SQLite checkpointer.

📚 Policy & Balance RAG

Runs SQL Tool + Qdrant Vector search for hybrid policy analysis.

📑 School Verification (HCS-11)

Calls Port 8001 microservice for child tuition cases & upload modal.

04
gather_evidence Hybrid RAG + SQL
Executes deterministic SQL queries for personal balance numbers AND vector similarity search against 121 policy passages with page coordinates.
05
generate_answer & validate_answer Synthesis & Guardrails
Synthesizes bilingual natural-language response. Validates against anti-hallucination guardrails and attaches verifiable citations ([Policy Name, Page #]).
06
finish_turn Frontend Delivery
Packages response markdown, structured interactive cards (Calendar pickers, Manager approval cards, Document upload triggers), and streams via SSE to the web client.

💼 Key Management Takeaways

1. Zero Hallucination Guarantee

Personal HR records (remaining leaves, probation status, manager transitions) are never generated by LLM guesswork; they are queried deterministically from the SQL database.

2. Verifiable Policy Citations

Every policy statement links directly to specific PDF policy pages, allowing employees and HR auditors to click and view the official clauses instantly.

3. Automated Compliance & Fraud Prevention

HCS-11 automatically validates child ages (4–18), UAE school accreditation, tuition fee caps, and duplicate submissions before triggering HR reimbursement.

4. Microservice Resilience

DalīlHR (Port 8000) and HCS-11 (Port 8001) operate as independent decoupled services. They can be scaled, updated, or tested independently without downtime.
